## 开始使用

以本地 Codex 为例，在存放安装包的文件夹打开聊天，发送：

```text
请检查“薄肌人生.skill.zip”，将其中的 boji-rensheng 完整文件夹安装到当前 Codex 可识别的个人技能目录。保留所有 references；若存在同名技能，先比较版本，避免重复安装。完成后确认可以找到它。
```

按[当前官方文档](https://developers.openai.com/codex/skills)，手动安装可将完整文件夹放入 `~/.agents/skills/`，入口为 `~/.agents/skills/boji-rensheng/SKILL.md`。安装后如未识别到，重启 Codex 再试。

然后发送：

```text
使用 $boji-rensheng，邵艾伦问投资方向和主业是否应该一致时，孙宇晨怎么回答？请讲清他的理由、例子，并给出原视频时间出处。
```

也可以问自己的问题：

```text
使用 $boji-rensheng，我正在考虑换工作。先问清楚最影响判断的情况，再结合访谈讨论。把嘉宾原观点和你对我的分析分开说明。
```

继续追问：

```text
这个建议成立需要什么条件？哪一条可能不适合我？资料没有回答的部分请直接说。
```

## 一个回答示例

问：看好一个行业，就应该转行吗？
